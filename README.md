# 7evyr.github.io

Links page at https://7evyr.github.io

## Add or change a link

Edit `links.json` (on github.com: open the file, press the pencil, then Commit changes). Each link looks like this:

```json
{
  "title": "Keep",
  "desc": "One line about it.",
  "tag": "Windows app",
  "url": "https://github.com/7evyr/keep-vault"
}
```

Put a comma between links, none after the last one. The page updates about a minute after you commit.
